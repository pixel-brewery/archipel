# Prisma JSON Schema Generator

`@pixel-brewery/archipel-prisma-generator-json-schema` is a Prisma generator that produces JSON Schema documents from your Prisma data model. Each model and enum gets its own schema file, tied together by a manifest file.

---

## Installation

Configure the `@pixel-brewery` GitHub Packages scope and authentication as
described in [Getting Started](/guides/getting-started#install-the-foundation)
before installing the generator.

```bash
yarn add @pixel-brewery/archipel-prisma-generator-json-schema
```

The generator depends on `@prisma/generator-helper` (bundled as a dependency).

### Prisma Compatibility

| Prisma Version | Status    |
| -------------- | --------- |
| 6.x            | Supported |
| 7.x            | Supported |

---

## Quick Start

Add the generator to your `schema.prisma`:

```prisma
generator jsonSchema {
  provider = "@pixel-brewery/archipel-prisma-generator-json-schema"
  output   = "./generated"
}
```

Run:

```bash
npx prisma generate
```

The generator creates an output directory with:

- A **manifest file** (`manifest.json`) referencing all generated schemas
- **Model schema files** (e.g. `User.schema.json`) for each Prisma model
- **Enum schema files** (e.g. `Role.schema.json`) for each Prisma enum

## Configuration

All options are optional strings in the Prisma generator block.

| Option                  | Description                                                            | Default                          |
| ----------------------- | ---------------------------------------------------------------------- | -------------------------------- |
| `fileName`              | Name of the manifest file                                              | `manifest.json`                  |
| `schemaFileSuffix`      | Suffix appended to each schema file name                               | `.schema.json`                   |
| `schemaVersion`         | JSON Schema `$schema` URI                                              | `https://json-schema.org/schema` |
| `emitGeneratorComment`  | Add a `$comment` field to each schema with generator metadata          | `true`                           |
| `modelNamingConvention` | JSON object with `prefix`, `suffix`, and optional `replace` for models | `{ "prefix": "", "suffix": "" }` |
| `enumNamingConvention`  | JSON object with `prefix`, `suffix`, and optional `replace` for enums  | `{ "prefix": "", "suffix": "" }` |

Boolean options accept `true`, `false`, `yes`, `no`, `1`, `0`.

### Naming Convention Object

Naming conventions are passed as JSON strings:

```prisma
generator jsonSchema {
  provider             = "@pixel-brewery/archipel-prisma-generator-json-schema"
  output               = "./generated"
  modelNamingConvention = "{\"prefix\": \"Schema\", \"suffix\": \"Model\"}"
  enumNamingConvention  = "{\"prefix\": \"Enum\", \"suffix\": \"\", \"replace\": {\"regex\": \"^Role$\", \"value\": \"Permission\"}}"
}
```

| Property        | Description                             |
| --------------- | --------------------------------------- |
| `prefix`        | String prepended to the schema name     |
| `suffix`        | String appended to the schema name      |
| `replace.regex` | Regex pattern to match on the name      |
| `replace.value` | Replacement string for the matched part |

## Examples

### Basic usage

```prisma
generator jsonSchema {
  provider = "@pixel-brewery/archipel-prisma-generator-json-schema"
  output   = "./generated"
}
```

Given a model `User` with fields `id` (String) and `email` (String), the generator produces `User.schema.json`:

```json
{
    "$schema": "https://json-schema.org/schema",
    "$comment": "This file was auto-generated by @pixel-brewery/archipel-prisma-generator-json-schema. Do not edit manually.",
    "title": "User",
    "type": "object",
    "properties": {
        "id": { "type": "string" },
        "email": { "type": "string" }
    },
    "required": ["id", "email"]
}
```

### Custom naming conventions

```prisma
generator jsonSchema {
  provider              = "@pixel-brewery/archipel-prisma-generator-json-schema"
  output                = "./generated"
  modelNamingConvention = "{\"prefix\": \"Schema\"}"
}
```

A model `User` produces `SchemaUser.schema.json` instead of `User.schema.json`.

### Disabling generator comments

```prisma
generator jsonSchema {
  provider             = "@pixel-brewery/archipel-prisma-generator-json-schema"
  output               = "./generated"
  emitGeneratorComment = "false"
}
```

The `$comment` field is omitted from generated schemas.

## Type Mapping

| Prisma Type | JSON Schema Type                                    |
| ----------- | --------------------------------------------------- |
| `String`    | `{ "type": "string" }`                              |
| `Int`       | `{ "type": "integer" }`                             |
| `Float`     | `{ "type": "number" }`                              |
| `Decimal`   | `{ "type": "number" }`                              |
| `BigInt`    | `{ "type": "integer" }`                             |
| `Boolean`   | `{ "type": "boolean" }`                             |
| `DateTime`  | `{ "type": "string", "format": "date-time" }`       |
| `Json`      | `{}` (any)                                          |
| `Bytes`     | `{ "type": "string", "contentEncoding": "base64" }` |

Nullable fields add `"null"` to the type array. List fields use `{ "type": "array", "items": ... }`. Enum fields use `{ "$ref": "./EnumName.schema.json" }`. Relations use `{ "$ref": "./ModelName.schema.json" }`.

## Manifest File

The manifest file (`manifest.json`) lists all generated schemas:

```json
{
    "$schema": "https://json-schema.org/schema",
    "schemas": {
        "models": {
            "User": "./User.schema.json",
            "Post": "./Post.schema.json"
        },
        "enums": {
            "Role": "./Role.schema.json"
        }
    }
}
```

Use this file for programmatic schema discovery or validation pipeline configuration.
