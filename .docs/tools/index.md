# Tools

Standalone developer tools that support the Archipel development workflow. These are not NestJS libraries — they are independent utilities.

| Tool                                                           | Description                                                                                                       |
| -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| [MCP Server](./mcp-server)                                     | Provides platform documentation and code patterns to AI-powered development tools via the Model Context Protocol. |
| [Prisma Entity Generator](./prisma-entity-generator)           | Generates strongly-typed TypeScript entity interfaces from a Prisma schema.                                       |
| [Prisma JSON Schema Generator](./prisma-json-schema-generator) | Generates JSON Schema validation documents from a Prisma schema.                                                  |
